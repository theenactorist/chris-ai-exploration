# Chris AI exploration

A static, responsive exploration for Chris AI by DreamPulze. Open `index.html` through a static web server to preview the page.

The example controls switch between locally authored scenarios. The demo request form is a frontend preview; submissions are disabled and no backend or AI service is connected.

The site needs no dependency installation or build step. `vercel.json` serves the project root as static files using Vercel's Other framework preset.

Photographs are AI-generated illustrative imagery. Google Sans license, notices and asset provenance are included in `assets/`.
